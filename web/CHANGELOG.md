# Changelog

## 0.0.2

* Changed light mode background to pure white (`#FFFFFF`) while maintaining radial gradients in dark mode.
* Updated TypeScript definitions and documentation.
* Rebuilt ESM and CommonJS bundles.

## 0.0.1

* Initial release of the DMF Logo SDK for React and Next.js.
* Physics-based kinetic animated splash screen (`SplashScreen`).
* Dual brand mark styles: `LogoStyle.dmfOneLine` and `LogoStyle.dmfFullLogo`.
* Dynamic Google Fonts auto-injector (Outfit, Plus Jakarta Sans).
* High-resolution embedded brand assets.
